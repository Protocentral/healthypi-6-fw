.. zephyr:board:: healthypi6_v3

Overview
********

Protocentral HealthyPi 6 v3 board documentation.

This is a pin-optimized revision of the v2 board using the same
STM32H757BITx (LQFP208) package. Key improvements include full
quad-SPI flash, enabled SPI6 expansion, and FDCAN1 support.

Refer to the original board documentation for details.
